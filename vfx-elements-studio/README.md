# Atmosphere & VFX Elements Studio Pro

रेडी-मेड वातावरण और VFX एलिमेंट्स (धुआँ, आग, धमाके, मौसम, आसमान, कण, पानी) — अपनी फ़ुटेज और फ़ोटो पर लगाएँ,
या अकेले एलिमेंट के रूप में एक्सपोर्ट करें (ग्रीन-स्क्रीन / ट्रांसपेरेंट / मैट)। सब कुछ प्रोसीड्युरल और सीडेड है —
प्रीव्यू और एक्सपोर्ट फ़्रेम-दर-फ़्रेम एक जैसे। एक्सपोर्ट हमेशा **साइलेंट** है।

## खोलें (कोई इंस्टॉल नहीं, पूरी तरह ऑफ़लाइन)

- **PC (Windows):** `Start VFX Studio.cmd` डबल-क्लिक करें — Chrome/Edge में खुल जाएगा।
  (या सीधे `Atmosphere & VFX Elements Studio Pro.html` डबल-क्लिक करें।)
- **फ़ोन पर:** उसी Wi-Fi पर `Open On Phone.cmd` चलाएँ (पहले Node.js लगा हो), फिर जो एड्रेस छपे वह फ़ोन के ब्राउज़र में खोलें।
  या पूरी `vfx-elements-studio` फ़ोल्डर फ़ोन में कॉपी करके HTML फ़ाइल खोलें।

## तेज़ शुरुआत

1. बाएँ **Elements** पैनल में प्रीसेट चुनें (hover करने पर कार्ड चलता है) — चुने हुए शॉट पर **＋** दबाकर लेयर जोड़ें।
2. बीच में **Stage** पर फ़ोटो/वीडियो खींचकर छोड़ें — वह उस शॉट का बैकग्राउंड बन जाता है (या "+ Photo" से चुनें)।
3. नीचे **Timeline** में: शॉट कार्ड के बीच ट्रांज़िशन चिप (कट / क्रॉस-फ़ेड / डिप-टू-ब्लैक), और नीचे की लेयर-बार को खींचकर
   एलिमेंट की टाइमिंग (start / अवधि) बदलें — हरा प्लेहेड दिखता है।
4. दाएँ **Inspector** में हर एलिमेंट के पैरामीटर (amount, size, speed, wind, tint, softness, seed, position, area,
   loop) — हर बदलाव तुरंत प्रीव्यू में दिखता है और अपने-आप सेव होता है।
5. **Export**: पूरा वीडियो (MP4), या एक शॉट का ग्रीन-स्क्रीन (#00FF00), ब्लू-स्क्रीन, ट्रांसपेरेंट WebM (असली alpha),
   या ब्लैक-व्हाइट मैट। साइज़: 720p / 1080p / 4K / Shorts 1080×1920 / स्क्वेयर। FPS: 24 / 25 / 30 / 60।

शॉर्टकट: **Space** = play/pause, **← →** = फ़्रेम-स्टेप, **Ctrl+Z / Ctrl+Shift+Z** = undo/redo, **Ctrl+S** = प्रोजेक्ट सेव।
`.vfx.json` प्रोजेक्ट फ़ाइलें Save/Open से मिलती हैं; बड़ी मीडिया फ़ाइलें स्टोर नहीं होतीं — नाम से दोबारा लिंक होती हैं।

## फ़ैमिली (55 प्रीसेट)

- **Smoke & fog** — पतला उठता धुआँ, काला युद्ध-धुआँ, चिमनी का सफ़ेद धुआँ, ज़मीनी कोहरा (loop), घना कोहरा,
  इम्पैक्ट पफ़, युद्धक्षेत्र की धुएँ की दीवार
- **Fire** — मशाल, कैम्पफ़ायर, जलती इमारत, आग की लाइन, अंगारे, चिंगारियाँ, जलता किनारा (फ़ोटो अंदर से जलती है),
  गर्मी की कँपकँपी (आपकी फ़ुटेज को मोड़ती है)
- **Explosions & impacts** — मज़ल फ़्लैश, दूर की तोपों की चमक, फ़ायरबॉल (शॉकवेव + मलबा + धुआँ), धूल का इम्पैक्ट,
  ज़मीन पर गोलियों के वार, फ़्लेयर/रॉकेट
- **Weather** — हल्की/तेज़/तिरछी बारिश, छींटों के साथ बारिश, हल्की बर्फ़, ब्लिज़र्ड, बिजली (ब्रांचिंग + आसमान की चमक),
  ओलावृष्टि, धूल का तूफ़ान, हवा में उड़ते पत्ते
- **Sky & light** — टाइम-लैप्स बादल, तूफ़ानी बादल, गॉड-रे, सन-ग्लेयर, चलती बादलों की छायाँ, तारों भरी रात, ऑरोरा
- **Particles & debris** — रोशनी में धूल के कण, गिरती राख, गिरता मलबा, उड़ते दस्तावेज़ (हिंदी टेक्स्ट सहित), बोकेह,
  गिरती पंखुड़ियाँ, भीड़ के कैमरे की फ़्लैश
- **Water** — लहरें (ripples), शीशे पर बारिश (बूँदें नीचे दौड़ती हैं), पानी के अंदर caustics, स्प्लैश
- **Combo looks** — युद्धग्रस्त शहर, पार्टीशन की रात, तूफ़ान का आगमन, डस्ट-बाउल, ठंडा मोर्चा, जलता अभिलेख

हर एलिमेंट में: density/amount, size, speed, wind, tint, softness, seed, position, area (कहाँ दिखे), loop length।

## वीडियो पाइपलाइन (CLI)

```bash
node build.mjs          # "Atmosphere & VFX Elements Studio Pro.html" बनाएँ (src से)
node render.mjs project.vfx.json out.mp4 --mode composite|green|blue|alpha|matte --fps 30 [--from S --to S] [--still S out.jpg]
node qa-sheet.mjs out.jpg [--fam "Weather" | --ids a,b]      # प्रीसेट कॉन्टैक्ट-शीट (QA)
node serve.mjs [--lan]  # http://localhost:7409 (+ फ़ोन का एड्रेस)
```

Python हेल्पर (`production/pipeline/vfx_fx.py`) — आपकी मीडिया से रेडी क्लिप:

```bash
python production/pipeline/vfx_fx.py --list
python production/pipeline/vfx_fx.py --preset cb-war-city --photo scene.jpg --out war.mp4
python production/pipeline/vfx_fx.py --preset we-rain-heavy --media clip.mp4 --out rain.mp4
python production/pipeline/vfx_fx.py --preset pa-paper-fly --photo scene.jpg --text "हिंदी परीक्षण" --out papers.mp4
python production/pipeline/vfx_fx.py --preset fi-embers --mode alpha --out embers.webm   # ट्रांसपेरेंट
```

render.mjs अपने-आप ढूँढता है: Remotion का chrome-headless-shell + ffmpeg (repo root के `node_modules` में),
फिर सिस्टम Chrome/Edge और PATH का ffmpeg। आउटपुट हमेशा यuv420p (BROADCAST RANGE) और साइलेंट है।

## नियम जो यह स्टूडियो मानता है

- कोई साउंड एफ़ेक्ट कभी नहीं — सारे एक्सपोर्ट में ऑडियो ट्रैक ही नहीं होता।
- सब कुछ सीडेड — एक ही seed = एक ही नतीजा, हर बार। प्रीव्यू == एक्सपोर्ट।
- ऑफ़लाइन: कोई CDN, कोई अकाउंट, कोई पेड API नहीं। फ़ॉन्ट बंडल किए हैं (Mukta, Kalam, Khand, Bebas Neue — OFL)।
- डिफ़ॉल्ट टेक्स्ट में कभी "AI" नहीं, कोई असली ब्रांड/व्यक्ति नहीं।
