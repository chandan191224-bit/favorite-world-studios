# Timeline Studio

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users and purpose

The user makes Favorite World documentary explainers on a Windows laptop and wants to create reusable After Effects-style timeline animations on a laptop or phone. Successful output is a polished moving documentary sequence: large media, dates, connected chronology, deliberate camera travel and narration holds, or a year ruler layered over footage.

## Confirmed constraints

- Offline self-contained HTML, free tools, no paid APIs or runtime CDN.
- Same dark-panel and amber-control family as the user's Clausd Paper/Map/Detective studios.
- Editable content, dates, images/cutouts, pacing, camera and style. Portable project saves; preserve user projects and imported media.
- Silent MP4/WebM, alpha/key/matte/PNG output; pipeline integration uses the same exact renderer.
- Phone layout and preview performance matter. Physical-phone testing remains unconfirmed.
- Research at least twenty YouTube videos. Existing evidence: 26 selected, 25 opening sampled-frame inspections, with explicit limitations.

## Current user feedback

“everythings looks so unprofessional , u didnt worked professionally and u didnt work on detailing”. The requested revision addresses animation composition, imagery, typography, motion detail and editor usability. Automated export checks alone do not establish craft quality.

## Existing stack and evidence

Static HTML/CSS/JavaScript, Canvas2D renderer, bundled Mediabunny, Node/FFmpeg PC renderer. Sources and tests live in this folder; installed studio is C:/Users/chand/Desktop/clausd/timeline-animation-studio. Original vector cutout demos were rejected as insufficiently detailed; original photorealistic cutout artwork is being authored and labelled illustrative. Actual photo credits remain preserved.
