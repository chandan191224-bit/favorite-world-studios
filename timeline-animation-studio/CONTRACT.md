# Timeline Animation Studio Pro — implementation contract

Offline, free, silent Canvas 2D editor. All source IIFEs attach to `window.TL`. Load order: util, templates, renderer, exporter, app. No runtime modules/CDNs. Root owns util/UI/build/export/tooling/docs; renderer worker owns ONE renderer file; template worker owns ONE templates file. Read research/REFERENCE_CATALOGUE.md when available. No user files changed outside this new studio.

Project schema:
```
{version:1,kind:'timeline-studio',name,title,subtitle,width:1920,height:1080,fps:30,duration:18,seed:42,
layout:'horizontal',theme:'archive',spacing:'equal',direction:'forward',
style:{background:'#e8dfcc',foreground:'#222a29',accent:'#b35430',secondary:'#7c8d76',font:'Georgia',lineWidth:4,nodeSize:12,textScale:1,grid:true,texture:0.15,showDates:true,showDescriptions:true,showHeader:true,showFooter:true,cardStyle:'plain'},
animation:{reveal:'draw',ease:'cinematic',stagger:0.7,drawDuration:1.2,hold:1.5},
camera:{mode:'overview',zoom:1,strength:0.4,panX:0,panY:0,rotation:0},
events:[{id,date:'1969',value:1969,endValue:1971,title:'An idea takes shape',description:'Editable demonstration milestone.',start:1,duration:1.1,lane:0,color:'',media:null,icon:'circle',offsetX:0,offsetY:0}],media:{},customPresets:[]}
```
Coordinates in renderer use normalized composition (1920x1080 base or portrait fit). Event `start` is seconds of REVEAL (independent from calendar `value`); duration seconds entrance; events remain visible until project end. `value` is numeric date for proportional scale; `date` display string permits BCE/full dates/Hindi; `endValue` enables duration/Gantt. Lane integer 0..3. Custom offsets are pixels in 1920x1080 reference coordinates. `spacing` equal/proportional; direction forward/reverse. Camera modes overview, follow, push, pull, drift; zoom .5..3, strength 0..1, pan pixels in base coordinates, rotation degrees. Export/pipeline must share exact renderer. Never render selection into export.

## root util
`TL.util={clamp,lerp,ease(p,name),rng,uid,clone,canvas,escape,slug,time,download,tick}`; `TL.duration(p)` returns numeric duration; `TL.validate(p)` sanitizes.

## renderer worker: src/core/renderer.js ONLY
Expose `TL.renderer.render(ctx,project,time,options={width,height,mode:'composite'|'alpha'|'green'|'blue'|'matte',editor:false,selected:null})`, `prepare(project,t)` async to cache embedded photos (media[id]={dataUrl,kind:'image',name}), `clearCaches()`, `positions(project,time,width,height)` returning array `{id,x,y,r}` screen centers for hit testing/dragging. Root stage dragging updates offsets from screen deltas corrected by output size. Editor draws all events fully revealed for arrangement. `positions` must match actual camera and be time independent in editor with camera overview? Accept optional fifth options object `{editor}` to match rendering. Media photos actual imports; fallback original procedural landmark/space/nature illustrations (no downloaded assets). Render event text/date/description using bounded wrapping and sensible type. Select outline when editor/selected only.

Required layout ids (18): horizontal, alternating, vertical, zigzag, serpentine, circular, spiral, branching, parallel, gantt, ticker, countdown, perspective, photo, archive, metro, staircase, chapters. Clearly distinct geometry, not just color swaps. Support up to 24 events, dates arbitrary, portrait composition. Fit all readable at overview (dense docs can opt follow). Proportional positions apply to horizontal/alternating/vertical/parallel/gantt/photo/archive/ticker. Trim path reveals synchronized to each start time; finish last event near 85–95% then hold. Camera follow tracks events smoothly. Counters interpolate numeric values, reverse timeline possible. Calendar rendering never claims fixed Gregorian parsing. Keep text within safe area; special circular labels must avoid collisions, use index outward. No ctx.filter/random/time-based noise; seeded cached texture. Exact green #00FF00 and blue #0000FF in empty corners, alpha transparent corners, matte white elements/black background (actual media silhouette white). Cache backgrounds/textures for sustained smooth playback.

## template worker: src/ui/templates.js ONLY
`TL.themes` object entries `{id,name,background,foreground,accent,secondary,font,grid,texture}` at least 8. `TL.layouts` array 18 `{id,name,family,description}`. `TL.cameraPresets` array 5 `{id,name,description}` same camera mode ids. `TL.templates` array >=30 entries `{id,name,family,description,layout,accent,make()}`. `TL.makeProject(id)` fresh project; `TL.eventDefaults(index=0)` fresh event sans id. No dependencies on renderer; can use TL.util. Each template 4–8 events (portrait 4–5), title/subtitle and descriptions thoughtfully original, demo content visibly marked illustrative (use real chronology only if verified). 18 layouts covered, 10+ families, meaningful differences e.g. duration bands vs parallel lanes, year slider vs counter. Default 'space-age' historical space timeline could be fictional to avoid source claims; prefer verified milestones 1957 Sputnik, 1961 Gagarin, 1969 Apollo11, 1998 ISS, 2021 Webb with title 'A journey beyond Earth' subtitle 'SPACE EXPLORATION / SAMPLE TIMELINE'. Template reveals paced across duration: first at 1.0s, last at duration-2.4s; do not make everything finish at 70%. Portrait template dimensions 1080x1920. Theme defaults merge style. No user fetched media, procedural placeholders okay. Export no sound.

## UI/root
Dark slate panels, warm amber controls; 270px library / center stage / 300px inspector; lower event reveal timeline. Phone <=900px stage top + Library/Events/Edit/Export tabs, no horizontal document overflow. Thumbnail pre-render to static data URLs and hover only when paused; Auto/Fast/Full preview resolution; portrait, landscape, square. Events editable date, numeric calendar value, end value, title, description, start/duration, lane, color, icon, photo, position; add/delete/duplicate/reorder/sort; bulk CSV import/export and JSON. Camera/style/animation controls. Undo/redo; IndexedDB portable media autosave + saved personal templates. API `TLS.load(p)`, `TLS.frame(t,mode,w,h)` async dataURL, `TLS.sheet(times,mode,width)`, `TLS.project` portable clone. UI `TL.app.project`, `TL.app.time`, `TL.app.select(id)`, `TL.app.refresh()`.

Review every preset at 25/45/65/85%; determinism, modes, real video decode, alpha decode, laptop/phone overflow, actual UI interactions, sustained performance. README + honest verification. Build one self contained HTML, serve/phone launchers, CLI/pipeline helper. Offline editor must not send network requests.
